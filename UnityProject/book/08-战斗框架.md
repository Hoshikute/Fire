# 战斗框架

## 设计思想

战斗框架是整个帧同步系统的核心场景，将 ECS 架构、帧同步机制、网络通信串联为完整的多人对战体验。核心设计原则：

1. **固定时间步长驱动**：200ms 一帧，所有逻辑在 FixedUpdate 中执行
2. **确定性保证**：相同输入产生相同输出，客户端和服务端共用逻辑代码
3. **预测+回滚**：本地先行执行，收到服务端权威数据后回滚重演算
4. **System 执行顺序即优先级**：DemoWorld 中 System 的注册顺序决定了每帧的执行流水线

## 战斗生命周期

```
匹配成功
  ↓
客户端: MainMenuStatus → GameStatus
服务端: MatchService.StartGame() → 创建 DemoWorld
  ↓
初始化阶段
  ├─ 服务端: 创建 Entity + ConnectionComponent + SyncComponent
  ├─ 客户端: WorldManager.Init(200) + CreateWorld<DemoWorld>()
  └─ InitSystem: 加载地图、初始化玩家组件
  ↓
战斗循环（固定 200ms 步长）
  ├─ 输入采集 → 命令发送
  ├─ 服务端收集命令 → 按帧广播
  ├─ 客户端执行逻辑帧
  └─ 表现层渲染
  ↓
GameSystem 倒计时归零
  ↓
结算阶段
  ├─ 服务端: SettlementService 计算排名和奖励
  ├─ 客户端: 显示结算 UI
  └─ 返回 MainMenuStatus
```

## 战斗初始化

### 服务端 — MatchService.StartGame()

匹配队列满员后触发：

```
StartGame(Player[]):
  ├─ world = WorldManager.CreateWorld<DemoWorld>()
  ├─ world.IsStart = true
  ├─ world.SyncRule = SyncRule.Status
  ├─ for each player:
  │   ├─ ConnectionComponent (持有 session 引用)
  │   ├─ SyncComponent (同步标记)
  │   └─ world.CreateEntityImmediately("Player" + id)
  ├─ 派发 ServiceEventDefine.c_playerJoin
  └─ 发送 PlayerMatchMsg_c(isMatched=true)
```

### 客户端 — GameStatus.OnEnterStatus()

```
OnEnterStatus():
  ├─ WorldManager.Init(200)           // 200ms 固定步长
  ├─ world = WorldManager.CreateWorld<DemoWorld>()
  └─ 注册网络消息监听（等待服务端同步数据）
```

### InitSystem — 玩家和地图初始化

当服务端派发 `c_playerJoin` 事件后，InitSystem 为每个玩家 Entity 添加完整组件：

```
PlayerJoin(entity):
  ├─ PlayerComponent
  │   ├─ characterID = ConnectionComponent.characterID
  │   ├─ 初始化 4 个元素 (各10个)
  │   └─ 加载 PlayerData (HP、速度等)
  ├─ CommandComponent (输入命令)
  ├─ TransfromComponent (出生位置 15,0,0)
  ├─ AssetComponent ("famale_01")
  ├─ MoveComponent (移动方向和速度)
  ├─ SkillStatusComponent (从 SkillData 表加载技能列表)
  ├─ CDComponent (技能冷却)
  ├─ CampComponent (阵营 = entity.ID)
  ├─ CollisionComponent (圆形, radius=0.5)
  ├─ LifeComponent (maxLife 从 PlayerData 读取)
  └─ BlowFlyComponent (击飞状态)

地图加载:
  ├─ mapData.txt → 创建障碍物 Entity (BlockComponent + CollisionComponent)
  └─ elementCreatePointData.txt → 创建物品生成点 Entity
```

## 战斗主循环

### WorldManager 帧驱动

```
Unity Update (每帧):
  ├─ s_UpdateTimer += deltaTime
  ├─ UpdateWorld() — 调用所有 System 的 Update/LateUpdate
  └─ while s_UpdateTimer >= IntervalTime (200ms):
      ├─ FixedUpdateWorld() — 执行逻辑帧
      └─ s_UpdateTimer -= IntervalTime

FixedLoop (每个逻辑帧):
  ├─ Record(FrameCount)           — 快照当前帧状态（用于回滚）
  ├─ FrameCount++
  ├─ NoRecalcBeforeFixedUpdate    — 仅首次执行（物品生成、倒计时）
  ├─ BeforeFixedUpdate            — 前置处理（操作应用、输入构建）
  ├─ FixedUpdate                  — 主逻辑（移动、技能、伤害、碰撞）
  ├─ LateFixedUpdate              — 后置处理
  ├─ NoRecalcLateFixedUpdate      — 仅首次执行
  ├─ LazyExecuteEntityOperation   — 延迟的实体创建/销毁
  └─ EndFrame
```

### DemoWorld System 执行流水线

每个逻辑帧按以下顺序执行：

```
┌─── 碰撞检测 ───────────────────────────┐
│ 1. CollisionSystem    — 更新碰撞列表    │
└────────────────────────────────────────┘
┌─── 输入处理 ───────────────────────────┐
│ 2. OperationSystem    — 命令→移动方向   │
└────────────────────────────────────────┘
┌─── 物理模拟 ───────────────────────────┐
│ 3. BlowFlySystem      — 击飞位移       │
│ 4. MoveSystem         — 位置更新+碰撞  │
└────────────────────────────────────────┘
┌─── 技能系统 ───────────────────────────┐
│ 5. FireSystem         — 技能触发判定    │
│ 6. SkillStatusSystem  — 技能状态推进    │
│ 7. SkillSystem        — 伤害/飞行物创建 │
└────────────────────────────────────────┘
┌─── 伤害处理 ───────────────────────────┐
│ 8. LifeSpanSystem     — 临时对象生命周期│
│ 9. CollisionDamageSystem — 飞行物命中   │
│ 10. FlyObjectCollisionSystem           │
└────────────────────────────────────────┘
┌─── 游戏规则 ───────────────────────────┐
│ 11. GameSystem        — 倒计时          │
│ 12. ResurgenceSystem  — 复活            │
│ 13. CreateItemSystem  — 物品生成        │
│ 14. ItemSystem        — 物品捡取        │
│ 15. RankSystem        — 排名更新        │
│ 16. BuffSystem        — Buff 效果       │
└────────────────────────────────────────┘
┌─── 初始化（首帧） ────────────────────────┐
│ 17. InitSystem        — 玩家/地图加载   │
└────────────────────────────────────────┘
```

## 输入与命令同步

### 完整调用链

```
客户端按键 (WASD / 鼠标)
    ↓
InputSystem.Update()
  ├─ 计算 moveDir (WASD → 方向向量)
  ├─ 计算 skillDir (鼠标位置 → 技能方向)
  └─ 记录 isFire (左键/技能键)
    ↓
CommandSyncSystem.BuildCommand()
  └─ 构建 CommandComponent {moveDir, skillDir, isFire, element1, element2}
    ↓
发送到服务端 (AffirmMsg)
    ↓
服务端 CommandMessageService
  ├─ 收集所有玩家当前帧的命令
  └─ 广播 CommandMsg (包含所有玩家命令)
    ↓
客户端 SyncSystem 接收
  ├─ 命令帧 == 当前帧 → 直接应用
  ├─ 命令帧 < 当前帧 → 需要回滚重演算 (Recalc)
  └─ 检测预测冲突 → 触发状态修正
```

### 预测与回滚

```
Recalc(targetFrame):
  ├─ 回退到 targetFrame-1 的快照状态
  ├─ 清除之后的历史记录
  └─ for frame = targetFrame to currentFrame:
      ├─ OnlyCallByRecalc() — 恢复该帧的命令
      ├─ 执行 BeforeFixedUpdate / FixedUpdate / LateFixedUpdate
      ├─ 处理缓存的服务器消息
      └─ Record(frame) — 保存新的快照
```

## 技能系统

### 技能触发 — FireSystem

```
BeforeFixedUpdate:
  for each entity (CommandComponent + CDComponent + SkillStatusComponent):
    ├─ 检查 isFire == true
    ├─ 检查 skillDir != zero (有方向)
    ├─ 检查 CD <= 0 (冷却就绪)
    ├─ 设置 CD = 2000ms
    ├─ 根据 element1 + element2 查 CombineData 表获取技能 ID
    └─ 设置 SkillStatusComponent.status = Before
```

### 技能状态推进 — SkillStatusSystem

技能是一个时间驱动的状态机：

```
Before (前摇)
  │ BeforeTime ms
  ↓
Current (执行中)
  │ 在 HitTime 触发伤害计算
  │ CurrentTime ms
  ↓
Later (后摇)
  │ LaterTime ms
  ↓
Finish (完成)

时间线:
├─ HitTime = BeforeTime + SkillInfo.m_HitTime  ← 此刻触发伤害
├─ CurrentTime = BeforeTime + CurrentInfo.m_Time
└─ LaterTime = CurrentTime + LaterInfo.m_Time
```

### 技能伤害执行 — SkillSystem

当 SkillStatusSystem 标记 `m_isHit = true` 时：

```
FixedUpdate:
  ├─ 1. 创建飞行物 (CreateFlyObject)
  │   ├─ 从 SkillData 获取飞行物 ID 列表
  │   ├─ 创建 Entity:
  │   │   ├─ FlyObjectComponent (伤害值、创建者、穿透属性)
  │   │   ├─ TransfromComponent (起始位置)
  │   │   ├─ MoveComponent (飞行方向和速度)
  │   │   ├─ CollisionComponent (碰撞半径)
  │   │   └─ LifeSpanComponent (存活时间)
  │   └─ 设置阵营 (CampComponent.creater)
  │
  ├─ 2. 范围伤害 (GetSkillDamageList)
  │   ├─ 根据 SkillData.m_EffectArea 创建效果范围
  │   ├─ 筛选范围内敌方实体:
  │   │   ├─ 有 CollisionComponent + LifeComponent + CampComponent
  │   │   ├─ 阵营不同 (creater != target.creater)
  │   │   └─ 存活 (life > 0)
  │   └─ 对每个目标调用 SkillUtils.Damage()
  │
  ├─ 3. 击飞处理 (BlowFly)
  │   ├─ 如果 SkillData.blowFlyID != "null"
  │   ├─ 设置 BlowFlyComponent.isBlow = true
  │   └─ 击飞方向 = 攻击者 → 目标 方向
  │
  └─ 4. Buff 施加 (DamageBuff)
      └─ 调用 SkillUtils.AddBuff() 添加到目标 buffList
```

## 伤害系统

### 飞行物碰撞 — CollisionDamageSystem

```
FixedUpdate:
  for each entity (FlyObjectComponent + CollisionComponent):
    ├─ 获取碰撞列表 (CollisionComponent.CollisionList)
    ├─ for each 碰撞目标:
    │   ├─ 检查阵营不同
    │   ├─ 检查目标存活
    │   ├─ 调用 SkillUtils.FlyDamageLogic():
    │   │   ├─ 造成飞行物伤害 (FlyObjectComponent.m_damage)
    │   │   ├─ 触发击飞 (如果有)
    │   │   └─ 施加 Buff (如果有)
    │   └─ 判断穿透:
    │       ├─ AcrossEnemy = true → 继续飞行
    │       └─ AcrossEnemy = false → 销毁飞行物
    └─ CollisionTrigger = true → 碰撞即销毁
```

### 击飞执行 — BlowFlySystem

```
BeforeFixedUpdate:
  for each entity (BlowFlyComponent.isBlow == true):
    ├─ blowTime -= deltaTime
    ├─ MoveComponent.m_velocity = distance / time * 1000
    ├─ MoveComponent.dir = blowDir
    └─ blowTime <= 0:
        ├─ isBlow = false
        └─ 恢复正常移动控制
```

### 伤害公式 — SkillUtils.Damage()

```
Damage(world, attacker, target, damageValue):
  ├─ LifeComponent.life -= damageValue
  ├─ 派发伤害事件
  ├─ life <= 0:
  │   ├─ 击杀者 PlayerComponent.score += 1
  │   └─ 派发 c_scoreChange 事件
  └─ RankSystem 重新计算排名
```

## Buff 系统

### Buff 数据结构

```
BuffInfo {
    buffID: string      — Buff 数据表 ID
    creater: int        — 施加者 Entity ID
    buffTime: int       — 已持续时间 (ms)
    buffCount: int      — 叠加层数
    hitTime: int        — 持续伤害计时器
}
```

### BuffSystem 逻辑

```
FixedUpdate:
  for each entity (PlayerComponent):
    for each buff in buffList:
      ├─ buffTime += deltaTime
      │
      ├─ 持续伤害判定:
      │   ├─ hitTime -= deltaTime
      │   └─ hitTime <= 0:
      │       ├─ 造成 BuffData.m_DamageNumber 伤害
      │       └─ hitTime = m_BuffEffectSpace * 1000 (重置间隔)
      │
      └─ 过期判定:
          └─ buffTime >= m_BuffTime * 1000:
              ├─ 派发 Buff 移除事件
              └─ 从 buffList 移除
```

### Buff 效果类型

| 效果 | 字段 | 说明 |
|------|------|------|
| 减速/加速 | m_SpeedChange, m_SpeedChangePercentage | 影响 GetSpeed() 返回值 |
| 眩晕 | m_Dizziness | OperationSystem 检查，阻止移动 |
| 持续伤害 | m_DamageNumber, m_BuffEffectSpace | 每隔固定间隔造成伤害 |

## 复活系统

```
ResurgenceSystem.FixedUpdate:
  for each entity (LifeComponent):
    ├─ life <= 0 (死亡状态):
    │   ├─ ResurgenceTimer += deltaTime
    │   └─ ResurgenceTimer >= 10000ms:
    │       ├─ life = maxLife (满血复活)
    │       ├─ ResurgenceTimer = 0
    │       └─ 派发 Recover 事件
    │
    └─ 死亡期间:
        └─ OperationSystem 拒绝所有移动指令
```

## 物品系统

### 物品生成 — CreateItemSystem

```
NoRecalcBeforeFixedUpdate (不参与重演算):
  for each entity (ItemCreatePointComponent):
    ├─ CreateTimer -= deltaTime
    └─ CreateTimer <= 0:
        ├─ 检查生成点周围无其他物品
        ├─ 随机选择物品类型 (randomList)
        ├─ 创建物品 Entity:
        │   ├─ CollisionComponent (radius=0.5)
        │   ├─ ItemComponent (物品数据)
        │   └─ AssetComponent (物品模型)
        └─ CreateTimer = 10000ms (10秒后再次生成)
```

### 物品捡取 — ItemSystem

```
FixedUpdate:
  for each entity (ItemComponent + CollisionComponent):
    ├─ 遍历碰撞列表
    ├─ 碰撞体有 PlayerComponent:
    │   ├─ PlayerComponent.AddElement(itemID) — 增加元素数量
    │   └─ 销毁物品 Entity
    └─ 只处理第一个接触的玩家
```

## 游戏结束与结算

### 倒计时 — GameSystem

```
NoRecalcBeforeFixedUpdate:
  ├─ GameTimeComponent.GameTime -= deltaTime
  └─ GameTime <= 0:
      ├─ world.isFinish = true
      ├─ world.IsStart = false
      └─ 派发 GameUtils.c_gameFinish
```

### 排名计算 — RankSystem

```
监听 c_scoreChange 事件:
  ReCalcRank():
    ├─ 收集所有 PlayerComponent 的 score
    ├─ 按 score 降序排序
    └─ 更新 RankComponent.rankList
```

### 结算处理 — SettlementService（服务端）

```
监听 GameUtils.c_gameFinish:
  ├─ 获取 RankComponent.rankList
  ├─ for each player (按排名):
  │   ├─ diamond = totalPlayers - rank (排名越高奖励越多)
  │   ├─ 更新数据库 player.Diamond
  │   └─ 发送 PlayerSettlement_c(rank, score, diamond)
  └─ 清理 World
```
