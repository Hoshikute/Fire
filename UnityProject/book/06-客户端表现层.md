# 客户端表现层（SyncClientLogic）

## 设计思想

表现层是**客户端独有**的逻辑，负责将 ECS 数据驱动的游戏状态渲染为可视化的 Unity 场景。核心原则：

1. 表现层只读取同步层数据，不修改同步层状态
2. 在 Update/LateUpdate 中执行，与同步帧解耦
3. 使用插值/平滑处理，避免逻辑帧的跳变感
4. 输入捕获由表现层完成，传递给同步层

## System 列表

| System | 职责 |
|--------|------|
| InputSystem | 捕获键盘/鼠标输入，构建 CommandComponent |
| CreatePerfabSystem | 根据 AssetComponent 创建 GameObject |
| MovePerfabSystem | 同步 GameObject 位置到 TransfromComponent |
| PlayerAnimSystem | 动画状态同步 |
| SkillBehaviorSystem | 技能特效播放 |
| BuffBehaviorSystem | Buff 特效显示 |
| CameraSystem | 摄像机跟踪本地玩家 |
| HealthBarSystem | 血条 UI 更新 |
| ClientOperationSystem | 操作反馈（如技能方向指示器） |
| SettlementUISystem | 结算界面 |
| ResurgenceUISystem | 复活倒计时 UI |
| DestroyEffectSystem | 实体销毁时的特效 |

## 核心 System 详解

### InputSystem — 输入捕获

在 `BeforeUpdate` 中读取玩家输入，写入静态 InputComponent：

```
BeforeUpdate:
  ├─ WASD → 计算移动方向 (syncvector3)
  ├─ 鼠标位置 → 计算技能方向
  ├─ 左键/技能键 → isFire = true
  └─ 写入 InputComponent（静态全局）

CommandSyncSystem 读取 InputComponent 构建 CommandComponent
```

### CreatePerfabSystem — 对象创建

监听实体的创建和销毁事件：

```
OnEntityOptimizeCreate(entity):
  ├─ 读取 AssetComponent.m_assetName
  ├─ ResourceManager.Load<GameObject>(assetName)
  ├─ Instantiate() 创建实例
  ├─ 创建 PerfabComponent (持有 GameObject 引用)
  │   ├─ 查找 HardPoint (挂载点)
  │   └─ 缓存 Transform
  └─ entity.AddComp(perfabComp)

OnEntityOptimizeDestroy(entity):
  ├─ 获取 PerfabComponent
  ├─ 播放销毁特效（可选）
  └─ Destroy(gameObject)
```

### MovePerfabSystem — 位置同步

在 `LateUpdate` 中将逻辑位置同步到 GameObject：

```
LateUpdate:
  for each entity (PerfabComponent + TransfromComponent):
    ├─ targetPos = TransfromComponent.pos (int → float 转换)
    ├─ 平滑插值: transform.position = Lerp(current, target, speed)
    └─ 旋转: 根据 MoveComponent.dir 设置朝向
```

### CameraSystem — 摄像机

跟踪本地玩家（带有 SelfComponent 的实体）：

```
LateUpdate:
  ├─ 找到 SelfComponent 实体
  ├─ 获取其 PerfabComponent.gameObject.transform
  └─ Camera.main.transform = 目标位置 + 偏移
```

### HealthBarSystem — 血条

```
Update:
  for each entity (LifeComponent + PerfabComponent):
    ├─ 计算血量百分比: life / maxLife
    ├─ 更新 Slider.value
    └─ 设置血条位置: WorldToScreenPoint(entity.pos)
```

## 客户端专属 Component

| 组件 | 用途 |
|------|------|
| PerfabComponent | GameObject 引用 + HardPoint 挂载点 |
| AnimComponent | Animator 引用 |
| HealthBarComponent | 血条 Canvas/Slider |
| SkillBehaviorComponent | 技能特效 ParticleSystem |
| BuffEffectComponent | Buff 特效引用 |
| OperationWindowComponent | 操作 UI 窗口引用 |
| PlayerCameraComponent | 摄像机配置（偏移、距离） |
| SelfComponent | 标记本地玩家的实体 |

## 与同步层的配合

```
┌────────────────────────────────────┐
│ SyncGameLogic (同步帧 FixedUpdate) │
│  更新 Component 数据              │
└──────────────┬─────────────────────┘
               │ 数据流（只读）
               ↓
┌────────────────────────────────────┐
│ SyncClientLogic (Update/LateUpdate)│
│  读取 Component → 驱动 Unity 表现 │
└────────────────────────────────────┘
               │
               ↓
┌────────────────────────────────────┐
│ Unity 渲染管线                      │
└────────────────────────────────────┘
```

**数据流方向：**
- InputSystem → InputComponent → CommandSyncSystem → 网络 → 服务端
- 服务端 → CommandMsg → SyncSystem → FixedUpdate → 表现层读取
