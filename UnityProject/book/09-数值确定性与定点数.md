# 数值确定性与定点数

## 设计思想

帧同步的核心约束是**确定性**：相同输入必须在所有客户端和服务端产生完全相同的输出。浮点数（IEEE 754）在不同 CPU 架构、编译器优化、指令集（x87 vs SSE）下可能产生不同舍入结果，因此本项目采用**整数运算**作为主方案，并预留了**定点数库**作为高精度备选。

本项目的两套数值方案：
1. **SyncVector3 + 整数放大 1000 倍**：主方案，简单高效，用于位置、速度、方向
2. **FixedMath + Vector2d（16 位移位定点数）**：备选方案，精度更高，项目中已实现但碰撞系统未接入

## 方案一：整数放大 1000 倍

### SyncVector3 — 整数向量

核心思路：将浮点坐标乘以 1000 转为整数存储，运算全程使用整数乘除。

```csharp
public struct SyncVector3 : IProtocolStructInterface
{
    public int x;  // 实际值 = x * 0.001
    public int y;
    public int z;
}
```

实际坐标 (1.5, 0, 2.3) 存储为 (1500, 0, 2300)。

### 转换方法

```csharp
// 整数 → 浮点（仅用于表现层渲染）
public Vector3 ToVector()
{
    return new Vector3(x * 0.001f, y * 0.001f, z * 0.001f);
}

// 浮点 → 整数（仅在初始化/输入采集时）
public SyncVector3 FromVector(Vector3 v)
{
    x = (int)(v.x * 1000);
    y = (int)(v.y * 1000);
    z = (int)(v.z * 1000);
}
```

### 运算符重载

```csharp
// 加减：直接运算，精度对齐
operator +(SyncVector3 a, SyncVector3 b) → (a.x+b.x, a.y+b.y, a.z+b.z)
operator -(SyncVector3 a, SyncVector3 b) → (a.x-b.x, a.y-b.y, a.z-b.z)

// 向量乘向量：需除以 1000 消掉多余放大
operator *(SyncVector3 a, SyncVector3 b) → (a.x*b.x/1000, a.y*b.y/1000, a.z*b.z/1000)

// 向量除向量：需乘以 1000 补偿
operator /(SyncVector3 a, SyncVector3 b) → (a.x/b.x*1000, a.y/b.y*1000, a.z/b.z*1000)

// 标量运算：整数直接乘除
operator *(SyncVector3 a, int b) → (a.x*b, a.y*b, a.z*b)
operator /(SyncVector3 a, int b) → (a.x/b, a.y/b, a.z/b)

// 浮点标量：转换后截断（精度损失点）
operator *(SyncVector3 a, float b) → ((int)(a.x*b), (int)(a.y*b), (int)(a.z*b))
operator /(SyncVector3 a, float b) → ((int)(a.x/b), (int)(a.y/b), (int)(a.z/b))
```

### 旋转操作

```csharp
// XZ 平面旋转（逆时针）— 注意：这里用了 Mathf.Sin/Cos（浮点）
public SyncVector3 RotateInXZ(float angle)
{
    angle *= Mathf.Deg2Rad;
    result.x = (int)(x * Mathf.Cos(angle) - z * Mathf.Sin(angle));
    result.z = (int)(x * Mathf.Sin(angle) + z * Mathf.Cos(angle));
    return result;
}
```

### 位置更新计算 — MoveSystem

```csharp
// 全整数运算（核心确定性保证）
newPos.x += (mc.dir.x * deltaTime / 1000) * mc.m_velocity / 1000;
newPos.y += (mc.dir.y * deltaTime / 1000) * mc.m_velocity / 1000;
newPos.z += (mc.dir.z * deltaTime / 1000) * mc.m_velocity / 1000;
```

**精度推导：**
```
dir.x = 方向分量（已放大 1000 倍）
deltaTime = 帧间隔毫秒（如 200）
m_velocity = 速度（已放大 1000 倍）

实际位移 = 方向 * 时间(秒) * 速度
整数位移 = (dir * deltaTime / 1000) * velocity / 1000
         = dir * deltaTime * velocity / 1000000
```

两次除以 1000 恰好消掉方向和速度各自的 1000 倍放大系数。

### 速度计算 — PlayerComponent.GetSpeed()

```csharp
public int GetSpeed()
{
    float speed = CharacterData.m_movespeed;  // 基础速度（配置表浮点数）

    // Buff 影响
    float changeNumber = 0;       // 绝对值加减
    float changePercantage = 1;   // 百分比乘数

    for each buff:
        changeNumber += BuffData.m_SpeedChange;
        changePercantage *= BuffData.m_SpeedChangePercentage;

    speed = speed * changePercantage + changeNumber;

    return (int)(speed * 1000);  // 转为整数输出
}
```

## 方案二：FixedMath 定点数库（16 位移位）

### 基本原理

用 `long` 类型的高 48 位存整数部分，低 16 位存小数部分。相当于所有数值放大 65536 倍。

```csharp
public static class FixedMath
{
    public const int SHIFT_AMOUNT = 16;
    public const long One = 1 << 16;       // 65536 代表 "1.0"
    public const long Half = One / 2;      // 32768 代表 "0.5"
    public const long Pi = (355 * One) / 113;  // 定点数 PI
}
```

### 创建定点数

```csharp
Create(long integer)    → integer << 16           // 整数转定点
Create(float f)         → (long)(f * 65536.0)     // 浮点转定点
Create(long num, long den) → (num << 16) / den    // 分数转定点
```

### 四则运算

```csharp
// 加减：直接运算（精度已对齐）
Add(long f1, long f2) → f1 + f2
Sub(long f1, long f2) → f1 - f2

// 乘法：结果右移 16 位还原精度
Mul(long f1, long f2) → (f1 * f2) >> 16

// 除法：被除数左移 16 位补偿精度
Div(long f1, long f2) → (f1 << 16) / f2
```

### 三角函数（泰勒级数实现）

### 转回普通数值

```csharp

RoundToInt(long f1)  → (f1 + 32767) >> 16 // 四舍五入
ToFloat(long f1)     → (float)(f1 / 65536.0)
ToDouble(long f1)    → f1 / 65536.0
```

## Vector2d — 定点数 2D 向量

基于 FixedMath 的二维向量，所有分量为 `long` 定点数。

```csharp
public struct Vector2d : IProtocolStructInterface
{
    [FixedNumber]
    public long x;
    public long y;
}
```

### 核心运算

```csharp
// 幅度（长度）
SqrMagnitude() → (x*x + y*y) >> 16
Magnitude()    → FixedMath.Sqrt(SqrMagnitude())

// 标准化
Normalize():
    mag = Magnitude()
    x = (x << 16) / mag
    y = (y << 16) / mag

// 点乘
Dot(otherX, otherY) → (x*otherX + y*otherY) >> 16

// 叉积
Cross(otherX, otherY) → (x*otherY - y*otherX) >> 16

// 距离
Distance(otherX, otherY) → Sqrt(((dx*dx + dy*dy) >> 16))

// 旋转（完全定点数运算）
Rotate(cos, sin):
    newX = (x*cos + y*sin) >> 16
    newY = (x*(-sin) + y*cos) >> 16
```

## 碰撞检测的实际实现

### 碰撞系统工作方式

CollisionSystem 将整数位置转为 float 后使用自定义几何算法判定：

```csharp
// CollisionSystem.FixedUpdate:
acc.area.position = amc.pos.ToVector();  // SyncVector3 → Vector3（整数→浮点）
acc.area.direction = amc.dir.ToVector();

// 然后调用
acc.area.AreaCollideSucceed(bcc.area)    // 浮点几何运算
```

### Area 碰撞区域

```csharp
public class Area
{
    public AreaType areaType;   // Circle / Rectangle / Sector
    public Vector3 position;    // 中心位置（float）
    public Vector3 direction;   // 方向
    public float radius;        // 半径
    public float length;        // 矩形长
    public float Width;         // 矩形宽
    public float angle;         // 扇形角度
}
```

### 碰撞检测算法

```
AreaCollideSucceed(area1, area2):
  根据两个 Area 的类型组合，调用对应算法:

  圆-圆:     Distance(a, b) < radius_a + radius_b
  圆-矩形:   扩大矩形(长+2r, 宽+2r)后判断圆心是否在内
  圆-扇形:   距离 + 角度双重判定
  矩形-矩形: 顶点包含 + 中轴线采样
  扇形-扇形: 关键点互相判定
  扇形-矩形: 关键点 + 顶点 + 采样点
```

### MoveSystem 中的碰撞阻挡

```csharp
IsCollisionBlock(Area area):
  ├─ 获取所有 BlockComponent 实体
  ├─ 将新位置设入 area.position
  ├─ 对每个障碍物调用 AreaCollideSucceed()
  └─ 有碰撞 → 返回 true → 位置不更新
```

## 确定性分析

### 完全确定的部分

| 运算 | 方式 | 原因 |
|------|------|------|
| 位置更新 | 整数乘除 | 整数除法截断在所有平台一致 |
| 速度/时间 | 整数毫秒 | 无浮点参与 |
| 网络传输 | int32 字段 | 无精度损失 |
| 帧推进 | 固定步长 200ms | 不依赖实际时间 |
| 状态快照/回滚 | 整数组件序列化 | 完美恢复 |

### 存在浮点风险的部分

| 运算 | 方式 | 风险程度 |
|------|------|---------|
| 碰撞检测 | Vector3.Distance (float) | 低风险 — 碰撞体远大于误差 |
| 旋转计算 | Mathf.Sin/Cos (float) | 低风险 — 结果截断为 int |
| 速度计算 | GetSpeed() 中间用 float | 低风险 — 最终 (int) 截断 |
| 扇形/矩形判定 | 浮点几何运算 | 极低风险 — 仅布尔结果 |

### 为什么实际运行中不出问题

1. **碰撞只产生布尔结果**：碰/没碰，不会把浮点误差写回位置数据
2. **位置数据始终是整数**：碰撞检测不修改 MoveComponent.pos
3. **误差量级差异大**：碰撞半径 0.5（500 整数单位），浮点误差在小数点后 7 位
4. **边界情况极少**：两个实体恰好在碰撞边界的概率极低
5. **最终截断**：所有浮点中间结果最终都 cast 为 int，消除了累积误差

### 如何做到严格确定性（改进方向）

如果要消除所有浮点风险，应该：
1. 碰撞检测改用 `Vector2d.SqrDistance()` 替代 `Vector3.Distance()`（避免开方和浮点）
2. 旋转改用 `FixedMath.Sin/Cos` 替代 `Mathf.Sin/Cos`
3. `GetSpeed()` 全程用整数运算
4. `Area` 类的成员从 float 改为 long 定点数

项目已有 FixedMath 和 Vector2d 的完整实现，但碰撞系统尚未接入。
