# 游戏逻辑层（SyncGameLogic）

## 设计思想

SyncGameLogic 是**客户端和服务端共享的游戏逻辑层**，两端代码完全一致。这是帧同步确定性的基础——相同的输入在两端产生相同的输出。

核心约束：
1. 所有计算使用整数（int32），禁止浮点数
2. `syncvector3` 使用 int32 而非 float 表示坐标
3. 逻辑只在 FixedUpdate 阶段执行
4. 不依赖任何平台特定 API

## DemoWorld — 世界配置

DemoWorld 定义了所有 System 的注册顺序（即执行顺序）：

```
1.  CollisionSystem          — 碰撞检测
2.  OperationSystem          — 输入应用到移动
3.  BlowFlySystem            — 击飞轨迹
4.  MoveSystem               — 位置更新
5.  FireSystem               — 技能触发
6.  SkillStatusSystem        — 技能CD管理
7.  SkillSystem              — 技能核心逻辑
8.  LifeSpanSystem           — 临时对象生命周期
9.  CollisionDamageSystem    — 碰撞伤害
10. FlyObjectCollisionSystem — 飞行物碰撞
11. GameSystem               — 游戏时间倒计时
12. ResurgenceSystem         — 复活
13. CreateItemSystem         — 物品创建
14. ItemSystem               — 物品收集
15. RankSystem               — 排名更新
16. BuffSystem               — Buff更新
17. InitSystem               — 玩家加入/地图初始化
18. ConnectSystem            — 连接管理（服务端）
19. PlayerInputSystem        — 命令收集（服务端）
20. ServiceSyncSystem        — 服务同步（服务端）
21. SyncDebugSystem          — 调试
```

## Component 清单

### 需要回滚的组件（MomentComponentBase）

| 组件 | 用途 |
|------|------|
| MoveComponent | 移动方向和速度 |
| PlayerComponent | 玩家数据（分数、Buff列表、元素） |
| LifeComponent | 血量、最大血量 |
| CDComponent | 技能冷却时间 |
| SkillStatusComponent | 技能列表和当前使用技能 |
| CommandComponent | 玩家输入（继承 PlayerCommandBase） |

### 单例组件（SingletonComponent）

| 组件 | 用途 |
|------|------|
| GameTimeComponent | 游戏倒计时（默认 10000ms） |
| RankComponent | 排名列表 |

### 普通组件

| 组件 | 用途 |
|------|------|
| TransfromComponent | 位置、旋转（支持父节点） |
| CollisionComponent | 碰撞区域（圆形，radius） |
| CampComponent | 阵营标识（creater ID） |
| AssetComponent | 模型资源 ID |
| BlowFlyComponent | 击飞状态和轨迹 |
| LifeSpanComponent | 临时对象存活时间 |
| FlyObjectComponent | 飞行物属性（伤害、创建者） |
| ItemComponent | 物品数据 |
| ItemCreatePointComponent | 物品生成点配置 |
| BlockComponent | 障碍物标记 |
| GrassComponent | 草地效果 |

### 玩家输入（CommandComponent）

```
CommandComponent : PlayerCommandBase {
    moveDir: syncvector3     — 移动方向
    skillDir: syncvector3    — 技能方向
    element1: int            — 元素1
    element2: int            — 元素2
    isFire: bool             — 是否释放技能
    id: int                  — 玩家 ID
}
```

## System 详解

### OperationSystem — 操作处理

将玩家输入转化为实体移动：

```
BeforeFixedUpdate:
  for each entity (CommandComponent + MoveComponent):
    ├─ 读取 CommandComponent.moveDir
    ├─ 检查击飞/眩晕状态 → 不能移动
    ├─ 计算 Buff 加成的速度
    └─ 设置 MoveComponent.dir = moveDir * speed
```

### MoveSystem — 移动系统

更新实体位置并处理碰撞：

```
FixedUpdate:
  for each entity (MoveComponent + TransfromComponent):
    ├─ newPos = pos + dir * velocity * deltaTime
    ├─ 碰撞检测：遍历 BlockComponent 实体
    │   └─ 圆-圆碰撞检测，阻止穿越
    ├─ 更新 TransfromComponent.pos
    └─ 更新 CollisionComponent.area.position
```

### SkillSystem — 技能核心

最复杂的系统，处理技能释放全流程：

```
FixedUpdate:
  for each entity (SkillStatusComponent + ...):
    ├─ 检查 isFire 且 CD 就绪
    ├─ 获取技能数据 (SkillData)
    ├─ 计算伤害范围内的敌方实体
    ├─ 创建飞行物 Entity:
    │   ├─ FlyObjectComponent (伤害、方向、速度)
    │   ├─ TransfromComponent (起始位置)
    │   ├─ MoveComponent (飞行方向)
    │   ├─ CollisionComponent (碰撞半径)
    │   └─ LifeSpanComponent (存活时间)
    ├─ 直接伤害处理: SkillUtils.Damage()
    ├─ 击飞处理: BlowFly()
    └─ Buff 处理: DamageBuff()
```

### GameSystem — 游戏管理

```
NoRecalcBeforeFixedUpdate:
  ├─ GameTimeComponent.GameTime -= deltaTime
  └─ GameTime <= 0 → 派发 GameUtils.c_gameFinish
```

### InitSystem — 初始化系统

在玩家 Entity 创建时执行：

```
PlayerJoin(entity):
  ├─ 从 ConnectionComponent 获取 characterID
  ├─ 添加 PlayerComponent（初始化元素数据）
  ├─ 添加 CommandComponent
  ├─ 添加 TransfromComponent（出生点）
  ├─ 添加 AssetComponent（模型ID）
  ├─ 添加 MoveComponent
  ├─ 添加 SkillStatusComponent（技能列表）
  ├─ 添加 CDComponent
  ├─ 添加 CampComponent
  ├─ 添加 CollisionComponent（radius=0.5）
  ├─ 添加 LifeComponent（从 PlayerData 读取 maxHP）
  ├─ 添加 BlowFlyComponent
  └─ 初始化游戏时间和地图

地图加载:
  ├─ mapData.txt → 创建障碍物 Entity (Block + Collision)
  └─ elementCreatePointData.txt → 创建物品生成点
```

### ResurgenceSystem — 复活

```
FixedUpdate:
  for each entity (LifeComponent):
    ├─ life <= 0 → ResurgenceTimer += deltaTime
    └─ ResurgenceTimer > 10000ms → 复活（恢复 maxHP）
```

### RankSystem — 排名

```
FixedUpdate:
  ├─ 收集所有 PlayerComponent 的 score
  ├─ 按 score 排序
  └─ 更新 RankComponent.rankList
```

### CollisionDamageSystem / FlyObjectCollisionSystem

处理飞行物命中目标后的伤害判定。

## 数据驱动

游戏逻辑依赖外部数据表：

| 数据文件 | 内容 |
|---------|------|
| PlayerData.txt | 角色属性（HP、速度等） |
| SkillData.txt | 技能配置（伤害、范围、CD） |
| SkillStatusData.txt | 技能状态配置 |
| BuffData.txt | Buff 效果数据 |
| FlyData.txt | 飞行物配置 |
| ItemsData.txt | 物品配置 |
| mapData.txt | 地图障碍物 |
| elementCreatePointData.txt | 元素生成点 |
| AreaData.txt | 区域配置 |
